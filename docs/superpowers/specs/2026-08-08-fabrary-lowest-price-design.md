# FaBrary 卡牌最低美元价格显示设计

## 目标

为 FaBrary 卡牌列表页和牌组页增加一个独立的油猴用户脚本，在每张牌图的右上角显示该卡所有印刷版本中 TCGplayer 美元报价的最低价。

目标页面：

- `https://fabrary.net/cards`
- `https://fabrary.net/cards/*`
- `https://fabrary.net/decks/*`

本功能与现有的 Talishar / FaBrary 中文卡牌浮窗脚本独立，不修改现有浮窗逻辑。

## 方案与边界

FaBrary 是单页应用，卡牌详情页的初始 HTML 不直接包含价格；价格由页面运行后加载。用户脚本不直接调用 Fabrary 的内部 GraphQL 接口，也不自行实现 AWS 请求签名，而是通过同源隐藏 iframe 打开对应的卡牌详情页，读取详情页已经渲染出的 TCGplayer 价格链接。

这样可以直接复用用户指定的卡牌详情页面和它当前的价格来源，同时避免绑定 Fabrary 的内部 API 配置、匿名请求权限或构建后的变量名。

不在本次范围内：

- 其他商店价格（CardTrader、Fluke and Box 等）。
- 非美元货币换算。
- 价格历史、价格图表或价格提醒。
- 登录、收藏、牌组编辑等站点交互。
- 修改现有中文卡牌浮窗脚本。

## 组件设计

### 1. 卡牌发现器

监听初始 DOM 和后续 DOM 变化，查找卡牌图片。对每张图片：

1. 优先从最近的卡牌链接取得 `/cards/<slug>` 地址。
2. 如果没有链接，使用图片 `alt` 文本生成卡牌 slug。
3. 为牌图创建或复用一个价格 badge，并将其放在牌图右上角。

价格 badge 使用 `pointer-events: none`，不会拦截牌图点击、拖动或悬停行为。脚本只处理顶层 FaBrary 卡牌/牌组页面；详情 iframe 内运行到同一用户脚本时直接退出普通扫描逻辑。

### 2. 价格加载器

使用一个复用的、移出视口的同源 iframe 顺序加载详情页。加载流程：

1. 将 badge 设为 `…`。
2. 导航 iframe 到卡牌详情 URL。
3. 等待详情页完成渲染；通过 DOM 观察和有限超时避免永久等待。
4. 查找详情页中指向 `tcgplayer.com` 的价格链接。
5. 从链接文本解析美元金额，取有效金额的最小值。
6. 将结果写入当前页面缓存，并更新所有相同卡牌 badge。

当前页面内以规范化卡牌 URL 为缓存键；同一张牌只加载一次。使用单请求队列配合可见区域检测，避免进入牌组页后立即为不可见的全部牌创建详情页请求。

### 3. 价格解析器

解析器只接受明确的美元文本，例如 `$1.25`；忽略空值、破折号、非美元货币和无法解析的文本。显示时统一保留两位小数：

- 有效报价：`$1.25`
- 页面无 TCGplayer 报价、详情页超时或加载失败：`—`

无报价不会阻塞页面，也不会弹出错误提示；调试信息只写入控制台。

## 页面生命周期

- 使用 `document-idle` 启动初始扫描。
- 使用 `MutationObserver` 处理 Fabrary 的 React 路由切换、分页、筛选和牌组内容变化。
- 使用 `IntersectionObserver` 只优先处理当前视口附近的牌图；不支持时退化为普通扫描。
- 监听 `scroll`/`resize` 只在必要时重新定位 badge，不改变卡牌布局。
- 页面路由变化时保留当前页内缓存，但清理已经不存在的 badge。

## 错误处理

- 找不到卡牌 URL：不创建或隐藏 badge。
- 详情页加载失败：显示 `—`，并允许后续 DOM 变化重新尝试。
- 详情页没有价格或价格文本不合法：显示 `—`。
- iframe 被站点策略阻止：显示 `—`，不影响主页面。
- 同一 URL 正在加载时复用已有 Promise，避免重复加载。

所有站点读取和 DOM 操作都限制在 `fabrary.net` 同源页面内；脚本不向第三方价格 API 发请求。

## 文件与测试

新增：

- `probe/fabrary-lowest-price.user.js`：可直接安装到 Tampermonkey/Violentmonkey 的用户脚本。
- `probe/test/fabrary-lowest-price.test.mjs`：纯函数和用户脚本行为测试。

测试重点：

- 从 TCGplayer 链接文本提取美元金额。
- 多个印刷版本取最低有效价。
- 忽略非美元、无效和缺失报价。
- 从卡牌链接/`alt` 识别规范化详情页 URL。
- badge 的加载、有价和无价显示状态。
- 处理重复 DOM 扫描时不重复加载同一卡牌。

## 验收标准

在给定的卡牌列表页和牌组页安装脚本后：

1. 可见牌图右上角出现价格 badge。
2. Blacktek Whisperers 等存在多个印刷版本的卡牌显示所有有效美元报价中的最低值。
3. 价格加载期间页面仍可正常滚动、点击和使用现有中文浮窗。
4. 无报价牌只显示 `—`，不会出现错误弹窗。
5. `cd probe && npm test` 通过，且用户脚本在静态检查中可被浏览器执行。
